# Winter Arc 2026 · JCA Tracker

A single-page tracker for a 70-day Winter Arc challenge and Supreme Court JCA exam preparation:
daily habits, study schedule (with Excel/CSV/PDF import), mock test marks, dashboard and study timer.

Open `index.html` directly, or host it free on GitHub Pages.

## Deploy on GitHub Pages
1. Create a new public repository (for example `winter-arc`).
2. Upload `index.html`, `.nojekyll` and `README.md` to the main branch.
3. Go to Settings > Pages, set Source to "Deploy from a branch", choose `main` and `/ (root)`, then Save.
4. After a minute your site is live at `https://<your-username>.github.io/<repo-name>/`.

## Data
Progress is saved in the browser (localStorage) on each device. Use "Export backup" and
"Import backup" in the sidebar to move your data between devices.
