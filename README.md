# JCA 2026 Study Tracker

A single-page tracker for Supreme Court JCA exam preparation: 21-day study schedule (with Excel/CSV/PDF
import), daily habits, mock test marks, dashboard and study timer.

## Deploy on GitHub Pages
1. Create a new public repository.
2. Upload `index.html`, `.nojekyll` and `README.md` (unzip first) to the main branch.
3. Settings > Pages > Deploy from a branch > `main` and `/ (root)`.

Progress is saved in the browser on each device. Use Export / Import backup to move data between devices.
